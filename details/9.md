# Personal Playlist Curation

## Description

- Creates personal sequence of shows/movies, increasing user engagement.
- Enhances loyalty of user with curated content aligned to user's preferences.

## Challenges

- accurate modeling of user's watching sequences is necessary.
- Continuous updates learning should be done based upon evolving user preference.

## Algorithm: Sequential Recommendation
Sequential Recommendation suggests items (movies, TV-shows) based on the sequential patterns of user interactions. It predicts the next item in a sequence by analyzing prior avaialable user behavior data. Improves List curation by analyzing the order and context of user interactions and predicts subsequent items using patterns observed in user viewing history, ensuring Lists are generated to cater user's preferences.

### Complexity

- **Time Complexity:** [sequence length]
- **Space Complexity:** O(n), [n is the number of items].
