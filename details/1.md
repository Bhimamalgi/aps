# Personalized Recommendation

## Description

- Personalised recommendations give each user a relatable edge to watch favoured content.
- Increases user's favourism towards the platform and reduces churn rate.

## Challenges

- Depends on amount of user data to accurately personalize recommendations.
- Difficulty in providing relevant recommendations for new users and the ones with limited history.

## Algorithm: Collaborative Filtering

Recommending items based on the preferences of users with similar tastes. It generates a user-item interaction matrix and uses similarity metrics to find items liked by similar users.
Doesn't rely on explicit item attributes but instead uses their interactions with items. By analyzing prior data of user-item interactions, predicts items that similar users have liked but user hasn't interacted yet.

### Complexity
- **Time Complexity:** O(m * n), [m is the number of users and n is the number of items].
- **Space Complexity:** O(m + n), [m is the number of users and n is the number of items].
