# Genre-based Suggestions

## Description

- Genres are easiest metric to learn ones movie/tv show taste
- Increases content consumption by suggesting relevant genres aligned with user preferences.

## Challenges
- Relies on accurate genre metadata of the movies/TV shows.
- Difficult to diversify recommendations within a single genre based on metadata availability.

## Algorithm: Content-Based Filtering
Content-Based Filtering recommends items based on the attributes (genre, plot summaries) of items which user has interacted with or liked and then assesses similarities between content using features.
It focuses on the intrinsic characteristics of items and user's preferences. After analyzing item attributes and user activity, predicts new content that might be similar to user's preferred genres and themes.

### Complexity
- **Time Complexity:** O(n * m), [n is the number of items and m is the number of features used for similarity calculation.]
- **Space Complexity:** O(n), [n is the number of items].
